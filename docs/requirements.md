# Constitution Requirements

*What every module must implement, and nothing about when: the phases and sequence live in the rollout plan [constitution-rollout-plan](rollout-plan.md), the kit's write-head. A module implements exactly its rows here ([law 4 of CLAUDE.md](../CLAUDE.md#law-4)).*


**Traceability matrix** — every aspect decomposed into requirement parts, each with exactly one primary destination. Destination classes: **kernel §n** (shared semantics), **Mx** (module, with artifact kind), **binding** (per-project `constitution.yaml` — never module content), **template** (authoring law). An authoring session for module X takes exactly its rows as the requirement set; coverage check = every part homed, every module = exactly its rows.

**Enforcement classes** — the closed set a row's last column is written in:

- **gate** (deterministic, red means fix, a blocking exit).
- **gate-lite** (a script that flags, blocking only where a dial turns it on, or checks presence alone).
- **advisory** (skill prose, judgment shaped and never gated).
- **definitional** (a kernel definition, enforced through another row's check).
- **config** (a binding validated at each read, malformed being a configuration failure).
- **git-native** (held by the repository itself).
- **review** (human judgment at review).

A row whose enforcement waits for another module says so in words.

**"Enters when" has two meanings** (decision [dec-0006-accumulating-set-first](decisions/dec-0006-accumulating-set-first.md)). For an accumulating module it names the first moment an object for the module exists. The module is authored *before* that moment. For a greenfield consumer the whole accumulating set is the day-one install set. For a self-limiting module it names the friction signal that earns authoring. Dials follow the consumer; modules never wait for calibration.

**Module boundaries remain provisional until authoring** — settled by three tests: *one invariant? one enforcement moment? one lifecycle trigger?* Flagged rows (†) sit on boundaries under test: M7 may dissolve (A8.x → M6). Settled: [A10.2](#a10-2) is M7's, the document half of the language aspect M9's (decision [dec-0046-language-module-rulings](decisions/dec-0046-language-module-rulings.md)). Settled: the M1/M2 boundary. [A2.3](#a2-3) is M1's, so one write-time script guards claimed territory. M2 is advisory creation (decision [dec-0015-pre-module-audit-rulings](decisions/dec-0015-pre-module-audit-rulings.md)).

The third is a list with an `installPath` that is no folder. The fix of an unreadable reply or of replies that disagree, on the pinned version, is to update the kit's reader that the line names. On another version, where the opt-out has the check run, the fix is to run again on the pinned one. The fix of the timed-out install is to run the check again and check that git can reach the install source. A `claude plugin list --json` that exits other than 0, or gives no result in its time, is a configuration failure too. Its fix is to run the check again.
