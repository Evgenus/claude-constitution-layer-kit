Friction in a project → commit note → recurring notes on one theme → module authored or amended in the kit → version bump → projects update. That is the principle [p2 of the intent page](../INTENT.md#p2), and, for a document of a kind no policy governs yet, [rule 5 of plc-0001-root-policy](policies/plc-0001-root-policy.md#r5).
