# The shared messages

*The messages of the code every gate shares, word for word. This page is a part of [kit-shared-gate-code](GATE.md), which tells what is shared and why; the table here is its section 3.*

<a id="g3"></a>
Each row is the text of `constitution_layer_kit/messages.py` under that key, word for word. There is one function per sub-key (`c5_…`, `c12_…`, `g1_skip_…`), and the row's handle is the table's, not the function's name. `{module}` is the namespace of the declared identity. `{clause}` is the closing clause of the identity (`until_installed`, and `until_fixed` in `C12.11`). Other `{…}` are parameters. In `C1` and `C14` to `C17`, which print before the identity is declared, the entry file hands it to `cli.version_failure` or writes it. A shared message that names the dials file names the one the declared identity carries. That is `constitution.yaml` in every module of this kit, as the rows below write it. `C15` to `C17` name the package, the version the module requires, the version found where there is one, and the path of the module's own `INSTALL.md` file. They close with the module's clause (R14 of [dec-0099-shared-code-installed-as-a-pip-package](../docs/decisions/dec-0099-shared-code-installed-as-a-pip-package.md#r14)). A configuration failure is one line that stands on its own. In hook mode only the first stderr line reaches the user (Claude Code 2.1.251, read 2026-09-18 to 2026-09-23). The line is followed by the count line `C11`.

<a id="g3a"></a>
A module's own message table takes the keys `G1`, `F9`, `F10`, `C1`, `C2`, `C5`, `C12`, `C14` and `C15` of this table only to state its part of that message. A key means one thing in every module, so a key of this table never names another message in a module's table. The family of a key is its letters and its first number. The family of C5.a and of C5.10 is C5, and the family of C4b is C4. A module's own key has a family that this table does not use. The kit's `scripts/check-handle-forms.py` holds that no other key of this table is taken, sub-keys included. A key of the module's table is a finding if its family is one of this table's. A family of a key this paragraph names is the exception. Whether a module's row under an allowed key states that module's part of the message is left to review.

An envelope that is YAML but no mapping is reported by the module with the shared detail `the block is not a mapping of field: value`. One nested past the parser's depth is reported with `brackets are nested too deeply to read` — an unreadable envelope, never a crash that lets the write through. Any other YAML error is the parser's whole message on one line, so the line and the column survive.

The tests of [item 8 of §2](GATE.md#g2) stop with lines of their own, from `constitution_layer_kit/testing/acceptance.py` and not from `messages.py`. Before any test runs, `acceptance.collected` raises pytest's usage error, exit 4. It gives one line for each test without a number, in the order collected, then the `H5` lines. pytest prints `ERROR: ` before the first. Under pytest-xdist the stop is its internal error, exit 3, without these lines, so `scripts/check-aspects.py` collects serially first. `{…}` is a parameter, as above.
