# The shared acceptance items

*The acceptance items of the code every gate shares. This page is a part of [kit-shared-gate-code](GATE.md), which tells what is shared and why; the table here is its section 5.*

<a id="g5"></a>
`constitution_layer_kit/testing/items.py`, run by pytest in each module's folder through the module's `tests/test_shared_items.py` file. Most items drive that module's real entry point. S168–S178 do not: they call `cli.version_failure`, the scope of the declaration and the module's own messages in the test's own process. S182 runs the shared reader in a process of its own. S188–S191 call the scopes of the declaration and the dials reader in the test's own process, for a gate of another layer. Each item is a test whose `item(…)` marker carries its number, unique and rising from 101. A new item takes a number no item has had, at the end of the file, so a number is never reissued. `scripts/check-aspects.py` holds the markers' numbers unique and rising from 101. It also holds every `S<n>` handle and range of this section, its table and its prose, against them. Review holds that no number is given again. `acceptance.collected` holds one more. Before any test runs, it stops the run on a number that two items carry. The two may be a module's own and a shared one, or any two (`H5` of [§3](MESSAGES.md#g3)).
