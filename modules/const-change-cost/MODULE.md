# MODULE.md — `const-change-cost`

*Draft at manifest version `0.0.1`, no open slots. This document is the module's description ([template](../../module-template/MODULE.md)). Every list and table row carries a handle.*

<a id="t1"></a>
## 1. Purpose

A person asks what a change cost: how many tokens the sessions spent to make the commits of a branch. Claude Code writes each reply of the model into the session's transcript with its token counts, and gives no count per commit. Three things defeat a count made after the fact. First, sessions copy each other's records. A forked session copies its parent's replies with the same ids and times, and on 2026-10-28, 3,699 of the 18,607 replies in the kit's own transcripts stood in two sessions or more, with no field to say which session made them. A tool that reads every transcript at once can then give a parent's work to its fork: in one run, the parent fell from $100.14 to $50.56 when the folders sorted the other way. Second, nothing records which session made a commit, or when a session started, unless a hook writes it at that moment; once the moment has passed, it is lost for good. Third, Claude Code deletes a command-line session's transcript after 30 days by default, without a message. This module logs each session's start and each commit as they happen. It counts the tokens of each commit's window with a pinned ccusage, over a folder that holds that one session alone, keeps the count in the clone, and shares it, when a person starts it, by the merge commit's trailers, the pull request's description and git notes.

<a id="t2"></a>
## 2. Failure class

**Accumulating**, the whole module (R13 of [dec-0116-tokens-per-commit-counted-by-ccusage](../../docs/decisions/dec-0116-tokens-per-commit-counted-by-ccusage.md#r13)). A session's start and the session behind each commit are lost for good when no hook records them as they happen, and the transcript a count reads expires with the platform's cleanup, so each session not logged is a count that can never be made. **Entry trigger:** the project's first session that commits. The module belongs in every project's day-one install set, and with it Node and npm on the first day. No other module carries any part of the count.

## 5. Invariant

**In a clone whose commit log is set up, every commit made by a session whose start that clone's start log holds gets, once its window is complete and while that session's transcript stands, one kept line of counts made from that session's own records alone — the records dated at or after its earliest logged start, of the replies whose first record falls after the session's previous commit and up to this one — so that no other session changes it; and the report names every commit of a range that has no kept line, with the reason.** "Commit log", "start", "window", "kept line" and "the file of counts" are this module's definitions ([§3](#t3), [§6](#t6)); "set up" is that both hooks of the commit log stand in the clone's git configuration; "while the transcript stands" is the honest boundary of [§9](#t9).

The advisory rules beside it:

1. **J-a** (advisory) When the start line says this clone logs no commit, tell the person, and run `setup-commit-log.sh` only when they ask: only a person changes git's configuration.
2. **J-b** (advisory) Before a pull request is opened and before it is merged, run `cost-report.sh --pr <range>` and let its block stand in the description; put the lines of `cost-report.sh --trailer <range>` into the last paragraph of the merge commit's message.
3. **J-c** (advisory) Write the counts as git notes with `cost-report.sh --notes <range>`, and push the notes ref, only on the person's word: a pushed ref publishes every count and cost.
4. **J-d** (advisory) Read every cost as the list price, a named compaction as work not counted, and an unpriced model's cost as a lower bound; never give a count as all of a session's work or as what was paid.

## 7. Dials

None. The module has no dials (R11 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r11)): nothing in its rows asks a project to calibrate anything, and a dial on any rule of the count would make two projects' counts mean different things. It has no gate, so neither `severity` nor `log_dir`; its output log is `${CLAUDE_PLUGIN_DATA}`, else nowhere ([rule 12 of kit-gate-script-rules](../../module-template/gate-script-rules.md#r12)). No entry reads the dials file, so its absence, or a fault in it, never stops a log that cannot be made later; a key written under `const-change-cost` in a project's `constitution.yaml` is read by nothing. Every cost is the list price of ccusage's table at the pinned version, and the report says so. The candidates of that ruling stand in [§12](#t12).

## 8. Boundary examples

The logs, the count and the report are deterministic; the fixtures are their pairs. The judgment is the skill's.

**Only a person changes git's configuration (J-a):**

1. The start line names the missing hooks, and the person asked for a typo fix → say once that this clone logs no commit and how to set it up, then fix the typo / *not* run `setup-commit-log.sh` unasked.
2. The person answers "set it up" → run `setup-commit-log.sh`, then `--check` / *not* write the keys with `git config` by hand.
3. The person says this clone should not log commits → leave it and do not raise it again in the session / *not* repeat it every turn.
4. A headless session that no person watches meets the line → name it in the final reply / *not* run the command because nobody can be asked.

**Share at the pull request and the merge (J-b):**

5. The session is to merge a branch on the person's yes → `cost-report.sh --trailer <base>..<branch>`, its lines in the merge message's last paragraph / *not* a merge message without them.
6. The session is to open a pull request → `cost-report.sh --pr <base>..<branch>`, the printed block in the description given to the forge / *not* a cost typed by hand.
7. The report names two commits not counted → the trailers as printed, the total saying how many were counted / *not* the trailers held back until every commit is counted.
8. The person will merge on the forge's page → give them the trailer lines to paste / *not* nothing, since no local hook sees that merge.

**Notes on the person's word (J-c):**

9. The person asks to share each commit's count with the team → `cost-report.sh --notes <range>`, then name the push command / *not* push the notes ref unasked.
10. Notes were written and a rebase is planned → say that the notes stay on the old commits unless `notes.rewriteRef` names their ref / *not* rebase in silence.
11. The repository is public and the person asked only for the pull request's block → the block alone / *not* notes as well.

**Read a figure for what it is (J-d):**

12. The report names a compaction in a window → "at least this many tokens; the compaction's work is not counted" / *not* the number as the window's whole cost.
13. A cost reads "at least $0.40" with an unpriced model → say "at least" and name the model / *not* "$0.40".
14. The person asks what the branch cost them → the list price, said as such / *not* given as the bill.

Exit codes of every entry: `0` done, nothing to do included, its closing or head line saying how many; `1` a configuration failure, the shared ones and J6; never `2`, since no entry has a finding.

**Honest limits.** The limits every gate shares: [kit-shared-gate-code §4](../../shared/GATE.md#g4); those that concern this module are 2, 3, 10, 11, 16, 17 and 18. This module's own, each with its backstop:

1. **Commits made before the setup command runs are never logged.** Only a person writes the hooks, so a clone's first commits can be lost. Backstop: J1 at every session start while a hook is missing; the report names each such commit (J11.1); W1 of [§13](#t13) counts them.
2. **A session with no logged start gets no count:** one started before the plugin was enabled, in another folder, or with `git -C` from outside the clone. Backstop: the report names its commits (J11.3); the day-one install keeps the case narrow.
3. **A compaction's tokens are not counted.** They reach no transcript (platform fact 12). Backstop: each compaction is named in its window, and every figure of that window is a lower bound by rule J-d.
4. **Every cost is a list price.** A project that pays another price sees the wrong cost, and a model newer than the pin has no price. Backstop: every output says "list price"; an unpriced model is named and its cost shown as "at least" (J10).
5. **A transcript swept before its window is counted is lost to the count.** Backstop: the count runs after each turn and at each start, long before the 30 days of platform fact 7; the report names the commit (J11.5).
6. **A commit that no git hook of this clone sees is not logged:** one made by a tool that writes commits without running git's hooks, or on a forge's page. A forge's merge brought in by a fast-forward is no new commit here, and the `post-merge` command logs only a merge commit whose reflog entry is no fast-forward. Backstop: the report names every commit of a range with no line (J11.1). The reflog's text is git's own and no promise: a git that changes it would log a fast-forward with the session that ran the pull.
7. **A process that inherits `CLAUDE_CODE_SESSION_ID`,** such as a background launcher a session started, keeps it, so a commit typed later in it is logged with that session (the comparison's d5, read, not run). Backstop: none — accepted; the commit's window holds only that session's own replies.
8. **A nested session that keeps no transcript** names a session whose records stand nowhere (the comparison's d6, read, not run). Backstop: the report names its commits (J11.5).
9. **An async count can be killed:** in a `-p` session at teardown (platform fact 4), or by a crash. A kept line is appended whole after its window's count, so a killed count writes none. Backstop: the next pass counts the window; `count-costs.sh` by hand.
10. **The windows run over the whole session.** While one agent works and another commits, the first agent's tokens until then go to that commit. Backstop: none — accepted, as R6 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r6) rules; the session's total is exact.
11. **A rewritten commit is a new commit.** After a rebase or an amend, the new commit's window runs from the session's previous logged commit, the old one keeping its count, so a range that holds only the new commits sums less than the work. Backstop: the report with no range lists every kept line, the old commits included.
12. **A session that ends with no record after its last commit** leaves that window waiting until the session is resumed. Backstop: the report names it (J11.4).
13. **The transcript's format is the platform's and undocumented.** The cutter reads five fields of a record; a field that moves shows as replies missing from a window. Backstop: the known-count fixture at the pin; the comparison of a window with a count made apart in the fixtures.
14. **The counts stay in the clone** and are lost with it; other clones never see them. Backstop: the trailers, the block and the notes, each started by a person.
15. **`--pr` knows one forge's command line, `gh`.** Elsewhere it prints the block. Backstop: the printed block, for a person to paste (J15.2).

## 11. Siblings

**Depends on:** [kernel §6](../../docs/constitution/CONVENTIONS.md#k6) (the namespace, zero configuration, the portability rule) and [§7](../../docs/constitution/CONVENTIONS.md#k7) (naming; a size in characters, so a count of tokens here is spend and never a size). Beside the kernel it needs git 2.54 or newer; Node and npm; the ccusage its lockfile pins; Python 3.12 or newer with PyYAML and the Python package `constitution-layer-kit`, which pip installs. That package is the kit's shared gate code and no sibling ([law 3 of CLAUDE.md](../../CLAUDE.md#law-3)). `gh` is optional, for `--pr` alone. **Kernel alone, with that package installed:** on a bare repository with no `constitution.yaml` the module works in full, since it reads no dials file: the start hook logs each start, the setup writes the hooks when a person runs it, and the count and the report read the clone's own folder. **Without git,** every entry stops at its first git call, in the shared `C3`, and no start is logged. **With a git older than 2.54,** starts are logged, the setup refuses (J6.10), and no commit is logged. **Without Node,** the logs run and the count stops with J6.1; once Node is there, the next pass counts every window whose transcript still stands. **Without npm,** a plugin loaded in place stops at J6.2; a copied plugin's install is the platform's, which needs npm too (platform fact 15). **Without Python or PyYAML,** each entry stops in the shared `C1` or `C2` with its own clause, and each commit shows the git hooks' failure, since their commands run `python3`.

## 12. Deferred

The deferrals every gate shares stand once in [kit-shared-gate-code §1](../../shared/GATE.md#g1). This module's own, each with its signal:

1. **A project's own prices,** through ccusage's `pricingOverrides`. Signal: a project that pays other than the list price asks for its costs (R11 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r11)).
2. **A dial that silences the start line.** Signal: a project reports it as noise where commits are left out on purpose (R11 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r11)).
3. **The count after each turn switched off.** Signal: a project reports it as slow (R11 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r11)).
4. **Compactions counted from the platform's OpenTelemetry export,** as a later dial. Signal: a project needs compactions counted (R14 of [dec-0116-tokens-per-commit-counted-by-ccusage](../../docs/decisions/dec-0116-tokens-per-commit-counted-by-ccusage.md#r14)).
5. **Windows per agent.** Signal: a project reports a parallel agent's work charged to another agent's commit (R6 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r6)).
6. **A stand-in start** for a session from before the start log. Signal: a project that enables the module after weeks of sessions asks for those commits (R7 of [dec-0117-change-cost-module-rulings](../../docs/decisions/dec-0117-change-cost-module-rulings.md#r7)).
7. **Transcripts named `<session>.orphaned-<…>.jsonl`** beside a session's own, which the copy leaves out and no survey ran. Signal: a session's count found short of the platform's own total where such a file stands.
8. **A second start log in the plugin's data folder,** for sessions that start outside the clone (the comparison's c7). Signal: commits skipped as J11.3 for that reason.
9. **A rewritten commit matched to its original** by `git patch-id` (the comparison's e6). Signal: a project that squashes or rebases its merges asks for per-change counts after landing.
10. **Another forge's command line for `--pr`.** Signal: a project on another forge.
11. **Ways of the effect report that [§13](#t13) leaves out:** B1, B3 and B4, since the module has no gate, and a reader rule, since a pattern sees each rule. Signal: a consumer commit note naming a way around the module.
