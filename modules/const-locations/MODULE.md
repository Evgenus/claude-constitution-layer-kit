# MODULE.md — `const-locations`

*Draft at manifest version `0.0.1`, no open slots. This document is the module's description ([template](../../module-template/MODULE.md)). Every list and table row carries a handle.*

<a id="t1"></a>
## 1. Purpose

A session is asked for a policy, a note, a record, and writes it where the conversation happens to be looking: a new directory, the repository root, beside the file it was reading. The document opens with whatever frontmatter the model last saw — a `date` field, an `id` that is not the file's stem, no `status` — or with none. Nothing resolves it to a policy, so nothing governs it; its shape matches no sibling, so the next document of its kind imitates it instead of the policy; and every one of them is retrofit debt: a move, an envelope repair and a link repair, each paid later by someone who did not write it. The kit observed the whole pattern on itself: every policy and module document it holds was written by hand from a neighbour's shape, and in the module's own live runs six documents out of six were born through a shell heredoc with the same three envelope defects. This module makes creation an act with a known outcome: a new document is born at the home its policy's territory implies, from that policy's template, with its envelope already valid — and a document of a kind no policy covers is not created until the policy exists.

<a id="t2"></a>
## 2. Failure class

**Accumulating.** Every document born outside its home or without its envelope is one more to move and repair when the kind is first governed, and one more exemplar for the next document to imitate wrongly. **Entry trigger:** the second territory — the first moment a session must choose between two homes; in practice day one of any project with more than one document kind, so the module belongs in the day-one install set.

## 3. Rows

## 5. Invariant

None: an advisory module claims no invariant. In its place, the rules, each `advisory` in its own text:

- **L-a.** A governed document is created through the command, never written blind: the command derives the home, proves it, and writes the envelope; the writer fills the body. *Advisory.*
- **L-b.** A document of a kind no policy covers is not created until the kind has its policy: the decision, the policy, the territory line, then the document — in that order. *Advisory.*
- **L-c.** The home follows from the territory and from nothing else: `<dir>/**` or `<dir>/**/*.md` gives `<dir>/<stem>.md`; a pattern with one free segment, `<dir>/*/NAME.md`, gives the path with the segment filled and the file name the pattern fixes; a single-path territory has no home, because nothing new is born in it. Any other territory has no home and the command says so. *Advisory in the skill; the command refuses what it cannot derive.*
- **L-d.** A template is the command's input, never an exemplar: the envelope's `id`, `title` and `status` are the command's values, `type` is the template's, every other field and the whole body are copied as they stand for the writer to fill; the rewritten block is written with line feeds and no byte-order mark before it, the body as the command read it. *Advisory.*
- **L-e.** What another kind's procedure owns stays there: a numbered kind's stem comes from the catalog's allocation, a record's `stakes`, `decider` and body from the record's procedure; this command takes the stem and gives the place. *Advisory.*
- **L-f.** The dials file is edited by hand: one namespace, keyed by the policy's id, with one `territory` line, at the end of the file; the readers validate it at the next write. *Advisory.*

**Error messages.** Each row is one function of this module's `messages.py`, under the same key; `{home}` is the derived repository-relative path, `{kind}` the policy id given. The command's lines are `L1`–`L4` on stdout; a refusal is a configuration failure of the act in the shared one-line shape, `BROKEN: {first line}: {why} — fix: {fix}` on stderr (a semicolon in place of the colon in C5.d), then the closing line `BROKEN: the document could not be created — nothing was written`, exit 1, the tree as it was. A why that the first line sets off after a colon or, in C5.d, a semicolon stands in its own cell, the colon or semicolon dropped; where the first line gives its reason otherwise, it stays whole in the first-line cell and the why cell reads `—`, as it does for a text that is no finding. The texts every gate shares — the dials file and the root policy (`C4`–`C9`), git, the interpreter and the shared package (`C1`–`C3`, `C12`, `C14`–`C17`) — are written out once in [kit-shared-gate-code §3](../../shared/GATE.md#g3); here `C1`, `C14`, `C15`, `C16` and `C17` drop the clause about unchecked writes, as the mover's do, and `C2` and `C12.11` close with the generator's own clauses — `until then nothing is created`, `until it is fixed nothing is created` — which its identity gives the shared code, since no write passes through a generator. Every value a text takes from a dial, a document, the command line or the environment goes through one of the two shared helpers, so a value with a line break leaves the line one line. What only points at something the reader can see elsewhere — a policy id, a territory pattern, a flag's value, a template's type — is shown as the shared `echoed` shows it: cut at 80 characters with the cut said, its backslashes and line breaks escaped. What the reader opens, copies or types into a fix is shown as the shared `escaped` shows it: the same escapes, never cut, since a cut path is no path to open — every path (the home on `L1`, `L3` and `L4` and in `L5.11` and `L5.12`, the template's path on `L2` and in `L5.14` to `L5.17`, the policy file's path in `L5.13`, the path that holds an id in `L5.19`, the home in `L5.20`), the directory of `L5.2` and the root of `L5.3`, the policy ids the reader picks from in `L5.5`, the policy id that `L5.24` tells the reader to write into the dials file, and the template's own parse error in `L5.16`. A `--stem`, `--segment` or `--id` holding a line break or a carriage return is refused by `L5.10`, which shows it escaped, before anything is written. Only one value stays raw: the system's error text of `L5.20` and of the unreadable-template case of `L5.15`, which already shows a path's line breaks escaped, as Python's error text does. The count line `L4` is the generator's examined count: one document created, or zero in a dry run, said as such. The grant prints its answer alone, one JSON object on stdout whose reason is `L6`, and no count line, since it examines nothing; a failure is the shared one-line shape on stderr closed by `L7`, exit 1, nothing granted. ## 7. Dials

Namespace `const-locations`. No `severity`: this module blocks nothing, and the key is refused under this namespace (C5.b) so that a line with no meaning is never a setting kept in silence. The specification's optional dial, "default policy for otherwise-unclaimed governed roots", is not implemented: a claim lives only in a policy's namespace and the constitution is silent outside claimed territory ([kernel §3](../../docs/constitution/CONVENTIONS.md#k3); [dec-0008-policies-by-location](../../docs/decisions/dec-0008-policies-by-location.md)), so the dial would claim from outside the kernel's one place for claims.

| dial | default | read by | meaning |
|---|---|---|---|
| `templates` | absent | the generator, through its `dials` part, in every run | the kinds that have a template: a list of `{policy: <policy id>, template: <repository-relative path>}`; a kind with no entry is created with the envelope alone; a policy listed twice is a configuration failure; a path is read as limit 15 of [kit-shared-gate-code §4](../../shared/GATE.md#g4) says |
| `log_dir` | absent | the shared output log, in every run of the generator | a repository-relative, git-ignored directory for the output log; absent: the platform's per-plugin data directory, else nowhere |

## 8. Boundary examples

**L-a — a governed document is created through the command.**

- **1.** *Violates:* asked for a policy on test naming, the session writes `docs/test-naming.md` with the frontmatter it last saw. *Complies:* it runs `new-document --kind <root policy id> --stem <stem> --title …`, which lands the policy where policies live with `type: current-state` from the root's template, then fills the body.
- **3.** *Violates:* to create a research comparison, the session copies the previous comparison and edits the copy. *Complies:* it runs the command; where the kind has no template the envelope alone is written and the body is the title's heading, and the previous comparison is read for its shape, not copied.
- **3a.** *Violates:* the command's first `BROKEN:` line names a missing interpreter, library or git, and the session writes the file by hand and calls it done. *Complies:* it installs what the line names and runs the command again.

**L-b — a kind has its policy before its first document.**

- **2.** *Violates:* asked for a working note, the session invents `docs/notes/` and writes there, no policy claiming it. *Complies:* it names the missing kind, and the notes policy is created first — a `process` decision, the policy through the command, a `notes-policy: {territory: ["docs/notes/**"]}` line by hand — then the note.
- **2a.** *Violates:* a request fits an existing kind's shape and rules, and the session opens a new policy for it. *Complies:* the kind exists, and the document goes there through the `new-document` skill.
- **2b.** *Violates:* in a repository with no `constitution.yaml`, the session writes a governed document anyway. *Complies:* it bootstraps once by hand — the dials file with `root_policy` and `module_prefix`, then the root policy — and from there the command works.

**L-c — the home follows from the territory.**

- **6.** *Violates:* asked for a second intent page, the session creates `INTENT-2.md`. *Complies:* the command refuses — the territory is a single path, nothing new is born in it — and the session says so.
- **6a.** *Violates:* a kind's territory is two patterns, and the session picks one of them as the home. *Complies:* the command refuses with no home, and the document is written by hand inside the territory.
- **6b.** *Violates:* a kind with the territory `packages/*/README.md` is given `--stem readme`. *Complies:* it is given `--segment alpha`, and the document is born at `packages/alpha/README.md`.

**L-d — a template is input, never an exemplar.**

7. *Violates:* after the command, the session rewrites the envelope's `id`, `type` or `status`. *Complies:* it leaves them as they are, and changes `title` only if the title was wrong.
8. *Violates:* the session adds sections the template does not ask for. *Complies:* it fills each placeholder, deletes the alternatives the template marks for deletion, and adds nothing else.
9. *Violates:* the kind has a template that fixes its `type`, and the session passes `--type` with another value. *Complies:* it drops `--type` and the template decides.

**L-e — what another procedure owns stays there.**

- **4.** *Violates:* a decision record is created through the command alone and left with `stakes` and `decider` unfilled. *Complies:* the record's procedure creates it — with this command's dry run for the home, or with the command writing the record template the dial names — and fills its own fields.
- **4a.** *Violates:* for a numbered kind, the session makes up the stem from the highest number it saw. *Complies:* it takes the whole stem from the project's numbering procedure and gives it as `--stem`.
- **4b.** *Violates:* for a kind whose own procedure writes the file, the session runs the command for real and then lets the procedure write the same path. *Complies:* it runs `--dry-run` first and hands the `HOME:` line to the procedure.

**L-f — the dials file is edited by hand.**

- **5.** *Violates:* the new kind's namespace is added by a script that rewrites `constitution.yaml`, losing its comments and renaming its anchors. *Complies:* three lines are appended by hand, and the next write of any gate validates them.
- **5a.** *Violates:* the new kind's territory is `docs/**`, which overlaps the root policy's territory. *Complies:* it is `docs/runbooks/**`, which no other territory touches.
- **5b.** *Violates:* a kind that holds many documents claims the single path `docs/runbooks/index.md`. *Complies:* it claims `docs/runbooks/**`, so a home follows for every new document.

## 9. Enforcement honesty

| # | artifact | kind |
|---|---|---|
| E1 | the skill `new-document` | `advisory` |
| E2 | the skill `new-kind` | `advisory` |
| E3 | the command `new-document.sh` and the generator behind it: its refusals are deterministic and teach, but they judge the act, never the repository — no finding, no exit 2 | `advisory` |
| E4 | the hook on `PreToolUse` and `grant-new-document.sh`: answers `allow` for exactly the module's own command with plain or single-quoted arguments, the allowlist of the hook row of [§6](#t6), and nothing for any other call | `grant` |

**Honest limits.** The limits every gate shares stand as [kit-shared-gate-code §4](../../shared/GATE.md#g4) gives them; those that concern a generator are 3, 5, 9, 10 and 11, and those that concern the grant are 2, 3, 10, 11 and 16. The module's own:

1. **A document written without the command is not seen.** A heredoc, a `Write`, an editor: nothing here fires. Backstop: the gate of module `const-meta-types` at write time and in the scan, when installed; the skill's description, which the comparison shows reaching the model.
2. **A home follows from three shapes of territory only.** Two patterns, a negation, a `*` inside a file name: no home, an honest refusal (L5.7). Backstop: the document written by hand inside the territory; the refusal names the shapes that work.
3. **The body is not checked.** The template's placeholders are copied, never filled or verified. Backstop: the kind's own procedure and review.
4. **The proof is before the write, and the write is one file.** Between the proof and the write nothing else runs; after it, another actor may move or edit the document. Backstop: the gates of the other modules, when installed.
5. **Id uniqueness is checked against the files git lists** — tracked, and untracked but not ignored — by reading every Markdown envelope. A git-ignored document with the same id is not seen. Backstop: the same rule in `const-meta-types`.
6. **`severity` under this namespace is read by the shared dials reader before this module refuses it**, so a bad value gets the shared text (C5.8) about a dial this module has not, and a good one is refused here (C5.b). Backstop: both exit 1 and name the line.
7. **A template's relative links are copied as they stand.** A template that lies at another depth than the home yields links that resolve from the template's place and not from the document's. Backstop: the scan of module `const-referencing`, when installed; the fix is a template at the home's depth, or links from the repository's top.
8. **The dials file is not edited.** The new-kind procedure's third act is by hand. Backstop: every gate validates the file at its next read.
9. **A `--type` given for a kind without a template is not checked against the kind.** The policy's prose says which meta-type its documents are, and the command cannot read prose. Backstop: the gate of module `const-meta-types`, when installed, holds the envelope; the `templates` dial, which makes the template decide.
10. **The carrier's permission is granted for one form of the command alone.** The skills load with no rule, since neither carries `allowed-tools` (platform fact 7), and the grant of row E4 approves the command in every mode. A call outside its allowlist is asked for as any other, and refused in a session that cannot ask: a command chained to another (`;`, `&&`, a pipe), a redirection, a value in double quotes or with `$` outside single quotes, a title with an apostrophe, which cannot stand in single quotes, and a plugin root with a space or another character the allowlist does not name. Two paths the grant does not see: a person's own alias or function named `sh` runs under it, and the command runs in whatever folder the shell stands in, so it may create a document in another repository with no prompt — the same document the command would create there when typed. A refused model was once seen to write the file by hand, blind — with the wrong `type` in the earlier comparison's live probe. Backstop: the skills tell the model to run the command alone, each value plain or in single quotes; a person answers the prompt; a deny or ask rule the consumer writes still wins over the grant (platform fact 8).
11. **The command's own write is no tool event.** The file is written by the script, so no write-time hook judges it — the gate of module `const-meta-types`, when installed, sees it in its scan and at the next `Edit` or `Write` of the file, never at creation. Backstop: the command's own proof before the write — the home, the id, the envelope's four fields from the template or the type given — and that scan.
12. **The shared package must be installed for `python3`,** since the plugin carries none (shared limit 3). Backstop: `C15`, `C16` and `C17` say so, exit 1, and point at the plugin's `INSTALL.md`, where the install command stands.
13. **The grant runs on every shell call that starts a subcommand with `sh `,** and on every call whose subcommands the platform cannot tell, since its `if` filter is best-effort (platform fact 8). Each such run costs a Python start (cost and budget in [§6](#t6)); where `python3`, the shared package or, on a match, PyYAML is missing, each such call shows the grant's failure line, and nothing is granted. Backstop: the failure line names the fix; the call goes to the platform's prompt.
14. **The kit's eval cannot prove the grant.** `claude plugin eval` removes a tool its run is not granted, and it honours its own grants alone: with the shell granted for `git status` only, the hook answered `allow` for the command and the run still refused it for its "don't ask" mode (platform fact 8). The module's cases grant the shell in full, so they prove that the skill is loaded and the command run, not that the grant approved it. Backstop: the fixtures T20–T27, which run the grant's entry point and so prove its answer; that the platform honours the answer rests on the live item V7 alone.

Exit codes of the command: `0` the document was created, or a dry run printed what a write would use; `1` refused — every refusal is asked before anything is written, so the closing line says nothing was written — or the command could not run: the shared failures and C5. Never `2`: a generator has no findings. Exit codes of the grant: `0` the answer was given, or the call is not the module's command and nothing is printed; `1` the grant could not run, and nothing is granted. Never `2`: a grant has no findings.

## 11. Siblings

**Depends on:** [kernel §1](../../docs/constitution/CONVENTIONS.md#k1) (the envelope), [§3](../../docs/constitution/CONVENTIONS.md#k3) (territory, policy, kind, resolution — the home is where the path binds the document to exactly one policy), [§6](../../docs/constitution/CONVENTIONS.md#k6) (the dials file, the module's own namespace, the dialect, portability), [§7](../../docs/constitution/CONVENTIONS.md#k7) (naming). Beside the kernel it needs the Python package `constitution-layer-kit`, which pip installs, as it needs Python and PyYAML. That package is the kit's shared gate code and no sibling ([law 3 of CLAUDE.md](../../CLAUDE.md#law-3)). Nothing else. The one external tool the generator preflights is git, beside `python3` and PyYAML: without any of them the command refuses on its first line, exit 1, and writes nothing (`C1`–`C3`); the two skills are prose and need no tool, but the command they name does.

**Kernel alone, with that package installed:** on a bare repository with no `constitution.yaml` the command refuses with L5.3 and the `new-kind` skill carries the procedure from zero — the dials file, the root policy, the first kind; with a dials file naming `module_prefix`, a root policy and one policy, every document of that kind is created at its home with the envelope alone, and the `templates` dial is the first calibration worth writing.

**Optional enhancements:**

1. When module `const-meta-types` is installed, a document born outside the command is caught at write time and in the scan; the command's own check is the proof either way; a document born by the command is judged by that gate only in its scan or at its next edit ([§9](#t9), limit 11).
2. When module `const-decision-records` is installed, its skill creates records, and this command offers it the place: the dry run names the home, or the command writes the file from the record template the dial names, and that skill fills `stakes`, `decider` and the body; this module reads nothing of that module's dial.
3. When module `const-catalogs` is installed, the stem of a numbered kind — prefix, number, slug — comes from that module's procedure and is given as `--stem`; this module reads nothing of that module's dial.
4. When module `const-referencing` is installed, its scan shows what a template's relative links break at the home's depth ([§9](#t9), limit 7).

## 12. Deferred

The deferrals every gate shares stand once in [kit-shared-gate-code §1](../../shared/GATE.md#g1); this list holds the module's own.

1. **A `home` override for a territory of the fourth class.** Not shipped: it restates the territory in a second place, and the kit has no such territory. Signal: a consumer whose kind is enumerated by two patterns or a negation asks the command for a home.
2. **The dials file edited by the command.** Not shipped: PyYAML loses the comments and renames the anchors, and a second YAML library is a preflighted dependency for an act that happens once per kind inside a procedure a human already reads. Signal: a consumer's commit notes reporting the manual step done wrong. Path: `ruamel.yaml` tuned to the file's layout, shown byte-identical on the kit's file in the comparison's first experiment.
3. **A hook-side assist.** Not shipped: `additionalContext` at `PreToolUse` taught the model to repair an envelope in the comparison's live run, but six of six free-choice runs created the file through the shell, where no handler fires, and `const-meta-types` holds the event. Signal: a consumer reporting documents born through `Write` with a wrong envelope while the skill was installed.
4. **Placeholder substitution in the body.** Not shipped: the kit's placeholders are `<…>` prose without a vocabulary, and every tool surveyed carries a template language for this. Signal: a consumer's template that needs the date, the title or the id inside the body.
5. **Relative-link repair when a template is copied to another depth.** Not shipped here: it is the referencing module's move repair applied to a copy. Signal: the kit's own module template, whose links gain one level in every copy ([CLAUDE.md](../../CLAUDE.md), step 1 of developing a module).
