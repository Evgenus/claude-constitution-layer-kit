# MODULE.md — `const-language`

*Draft at manifest version `0.0.2`, no open slots. This document is the module's description ([template](../../module-template/MODULE.md)). Every list and table row carries a handle.*

<a id="t1"></a>
## 1. Purpose

The documents a project governs are read by people whose first language is not English and by a model that reads them in every session, and nobody measures what that reading costs. The kit's own tree, measured on 2026-09-27 before any rule existed (E2 of the comparison): a median Flesch–Kincaid grade of 9.33 over 109 documents, 38 of them above grade 10 and the guide of every session at 13.22; 2,890 of 9,598 sentences over 25 words, 66 over 100, the longest 261; every one of a sample of passives a real passive, the register of the whole tree. Each document decides its own density at the moment of writing, and the reader who cannot follow a 60-word sentence has no number to point at. This module gives the project the numbers — a grade ceiling, a words-per-sentence limit, two short lists of the constructions plain language avoids — holds them in the dials file, and checks every covered document against them after each write and in a scan, with Vale doing the counting.

<a id="t2"></a>
## 2. Failure class

`self-limiting`: dense prose is felt by the reader of that document and fixed there; nothing compounds across the repository except a template's prose, which its documents inherit until the template is fixed. **Entry trigger:** the first prose-complexity complaint — a reader, a reviewer or a consumer session saying a document could not be followed, a sentence had to be read twice, a term was never defined — made twice. The kit did not pass it: the module was started ahead of the trigger by the decider's choice, the objection recorded (decision [dec-0046-language-module-rulings](../../docs/decisions/dec-0046-language-module-rulings.md), section 1), and the numbers of [§1](#t1) are what the tree showed at the survey, not the trigger.

## 5. Invariant

**No covered document, as Vale reads its prose, is above the grade ceiling, holds a sentence over the word limit or holds a phrase of the forbidden or simpler lists at level error, save where an entry of the `departures` dial allows that rule for the document; and none holds a Vale comment outside a fence or a code span.** "Covered": among the Markdown files git lists, tracked and untracked, ignored ones excepted, the ones the dial `territories` names. "As Vale reads its prose": the document with its envelope and every Vale comment outside a fence or a code span blanked, line numbers kept, read by Vale 3.23.0 or newer with the configuration of [§7](#t7) — the grade over the `summary` scope, the words over each sentence, the phrases over the text outside code spans, code blocks and URLs, case-insensitively. "At level error": the rule's level in the dial `levels`; a rule at warning reports a note and holds nothing, a rule at off is not written. "Allows": an entry whose `paths` match the document and whose `allow` names the rule; a hit of such a rule in such a document is neither a finding nor a note. The invariant holds after every write of a covered document through the file tools and at scan time; no write is refused ([§9](#t9)). After a write, coverage is by pattern alone: the hook judges a written file the patterns hold whether or not git ignores it, while the scan lists only what git does not ignore (limit 9 of [§9](#t9)).

The advisory rules beside it, each `advisory` in its own text, stated in the skill:

- **L-a.** One idea per sentence; a sentence past the limit is split at a clause, never squeezed. *Advisory.*
- **L-b.** The plain word: the one a reader meets first; the finding names it. *Advisory.*
- **L-c.** No idiom: a phrase whose meaning is not the meaning of its words is said plainly. *Advisory.*
- **L-d.** Name who acts; the passive is a register the project sets, not a defect the gate reds. *Advisory.*
- **L-e.** A term of the project's own or of the trade is defined in one clause at first use. *Advisory.*
- **L-f.** A phrase the project keeps on purpose is an exception in the dials file; a document that must not be edited is declared as a departure there, with its reason; nothing is marked in a document. *Advisory.*

**Error messages.** Each row is one function of this module's `messages.py`, under the same key; `{path}` is a document's repository-relative path, `{line}` a line number, `{text}` a value echoed from the document, cut at 80 characters with the cut said, then escaped. So is `{plain}`, the pair's plain word from the dials, in a headline, and every key or value a C5 text echoes from the dials file. A value the reader opens, types or acts on stands whole, however long, escaped and never cut: `{path}`, `{plain}` in a fix, Vale's own words in a C12 text. Escaped means a backslash and a line break are shown as `\\` and `\n`, so that each line stays one line. A finding is `RED`, three lines (what failed / why the rule exists / the exact fix), followed by the count line and then by the shared line F10. ## 7. Dials

| dial | default | read by | meaning |
|---|---|---|---|
| `severity` | `block` | the hook | As every hook gate's ([template §7](../../module-template/MODULE.md#t7)): `block` hands the findings to the model as a block beside the tool result, exit 2, the write already made; `warn` hands them as context, exit 0. The scan ignores it and is red on any finding. |
| `log_dir` | absent | both | As every gate's ([template §7](../../module-template/MODULE.md#t7)). |
| `territories` | `["*.md"]` | both | The documents the gate reads: path patterns in the dials file's dialect over the Markdown files git lists, tracked and untracked, ignored ones excepted; a negated pattern takes files out, and a written file the patterns do not hold is a visible skip. Empty: refused. |
| `grade_ceiling` | `10` | both | The Flesch–Kincaid grade a document may reach, a finite number, 0 or more; a document whose grade, as Vale computes it over the `summary` scope, is above it is L1. |
| `sentence_words` | `25` | both | The words a sentence may hold, a whole number of 1 or more; a sentence over it is L2, a heading being a sentence. |
| `levels` | `{grade: error, sentence: error, forbidden: error, simpler: error, passive: warning}` | both | The level of each rule, any subset overriding the default: `error` is a finding, red; `warning` is a note, never red; `off` is not written — and a bare `off`, which YAML reads as the boolean false, is taken as that level. Every rule off: refused. |
| `forbidden` | `[]` | both | Phrases of the project's own added to the founding forbidden list, one line each, matched case-insensitively at word boundaries. |
| `simpler` | `{}` | both | Pairs of the project's own added to the founding simpler list, the phrase as the key and the plain word as the value. |
| `exceptions` | `[]` | both | Phrases of either list the project keeps on purpose, removed from the rules before Vale runs; a phrase no list holds is refused. |
| `departures` | `[]` | both | What stands as written, where, and why: entries `{paths: [<patterns>], allow: [<rule keys>], reason: <one line>}`. `paths` is gitignore syntax — a pattern for a kind of document, a number range by a character class such as `docs/records/rec-00[0-3]*.md`, or one file by its path with a leading slash; `allow` names rules by key from the five; `reason` is required and one line; a line break at either end, which a YAML block scalar gives at its end, is trimmed with the other white space there, one inside it is refused. A hit of an allowed rule in a matched document is neither a finding nor a note; the other rules still apply there. An entry matching no covered document is a note on every scan. A malformed entry, an unknown field, an empty or multi-line reason, a pattern git would misread: a configuration failure naming the entry. The kit's own: one entry, by path, for the four accepted records and frozen comparisons whose long sentences are lists no wording edit splits; the others meet the thresholds by the wording edits their policies allow (decision [dec-0048-frozen-documents-take-wording-edits](../../docs/decisions/dec-0048-frozen-documents-take-wording-edits.md)). |

The founding lists, the module's own, in `scripts/language_gate/rules.py`: thirty forbidden phrases — idioms of the trade such as `hit the ground running`, `low-hanging fruit`, `circle back` and `silver bullet`, hedges such as `needless to say` and `it is worth noting that`, and formal words with no one-word replacement such as `notwithstanding`, `aforementioned` and `heretofore` — and thirty-three simpler pairs, `prior to` → `before`, `in order to` → `to`, `utilize` → `use`, `in the event that` → `if`, `with regard to` → `about`, `a number of` → `some`, and the rest; the two lists are disjoint, held so by fixture T17. The passive pattern is a form of *be* followed by a regular participle of four letters or more ending in `ed`, or one of forty-eight irregular participles by name. A phrase of the repository's own that is also a key of the simpler list is reported by both rules; an exception matches a phrase in any case, as the lists do.

What the gate hands to Vale: the document with its envelope — from a first line `---`, a byte-order mark before it allowed, to the next line `---`, trailing whitespace aside on both — replaced by one empty line for each line feed it holds, so the text after it keeps the count of line feeds before it. A line of the envelope ends at a line feed, a carriage return and line feed, or a lone carriage return, and nowhere else. Every `<!-- vale … -->` comment outside a fence or a code span, on one line or across lines, is replaced by spaces, so that line numbers are those of the document; one inside a fence or a code span is a mention Vale does not honour, left as it stands. The copies stand flat in a temporary tree, each under a numbered `.md` name (`000000.md`, `000001.md` and on), beside a configuration of one section, `[*.md]` with the one generated style, and a `MinAlertLevel` of `suggestion` so that a rule at warning reaches the gate. So Vale reads every covered document as Markdown, whatever the case of its ending (`X.MD`, `Guide.Md`) and whatever its name, one that starts with a dash included, which Vale would read as an option. The gate maps each result back to the real path before any finding, so a finding carries the document's own path and line. Vale runs once over the copies with `--no-exit`, so its exit 1 on a finding is not read as a failure, and any other exit is the configuration failure of [§6](#t6).

## 8. Boundary examples

Each pair reads *violates / complies*. The gate's own lines are numbers; the boundaries below are the module's judgment lines and the moments where a number is not the answer.

**A finding, or an exception** ([A10.1](../../docs/requirements.md#a10-1)):

1. `Leverage the cache` in a design note → L4, write `use` / a project whose product is named `Leverage` lists `leverage` in `exceptions`, once, with the reason in the commit.
2. "The record was accepted" in a policy where the actor is the decider → a passive the reader must resolve, name the decider / "the record is accepted" in the same policy where who accepts is stated in the sentence before — the passive kept by `levels.passive: warning`, the note read and left.
3. A 40-word sentence that lists four cases with a semicolon each → L2, split into a sentence per case / a 24-word sentence holding two ideas — passes the gate, fails rule L-a, and is the writer's to split.
4. A comparison quoting the phrase `in order to` in a code span → not a finding: code is not prose / the same phrase in running text explaining why it is forbidden → L4, and the exception is the wrong fix; put the phrase in a code span.

**A threshold, or a rewrite** ([A10.1](../../docs/requirements.md#a10-1)):

5. A repository of dense documents adopting the gate → `grade_ceiling` raised to what the tree bears and lowered in steps, each a commit with the number and the reason / the ceiling raised once to where nothing is red and left there — a gate that reds nothing.
6. A frozen record that no rule allows editing, red under the ceiling → a departure over its number range allowing the rules it fails, with the reason that accepted records stand as written, the gate still reading it for the rest / a Vale comment written into the record — a mark the gate reports, and an edit of a frozen document; or a negated pattern taking it out of the territory, which hides it from every rule.
7. A kernel document at grade 12 under a ceiling of 10 → rewritten under its own change with its own audit, the ceiling above it until then / rewritten inside another module's change as a side effect.

**A rule, or the writer** ([A10.1](../../docs/requirements.md#a10-1), [A10.2](../../docs/requirements.md#a10-2)):

8. A term of the project's own used without a definition → rule L-e, the writer's, no finding / a definition demanded by a gate — judgment dressed as a check, which the module does not ship.
9. A reply in chat of 70-word sentences → the sibling's session-start rule, no measurement / the last reply run through Vale at `Stop` — rejected: the reply is shown before the hook runs, and a block there is a second reply that restates the first.

**Honest limits**, each with its backstop. The shared code's limits — [kit-shared-gate-code §4](../../shared/GATE.md#g4) — apply. This module's own:

1. **The numbers are Vale's.** The grade is Flesch–Kincaid as Vale counts words, sentences and syllables, and other tools give the same text a grade one to three years apart (E5 of the comparison); a ceiling is checkable only as "grade N by Vale's Flesch–Kincaid", which is what the dial means. A later Vale that counts differently moves every document's grade, and the fixtures that type a grade say which version counted. Backstop: the version floor; the fixtures; a consumer's dial.
2. **A sentence is what Vale ends.** A heading is a sentence to the word limit and no prose to the grade; a list item is a sentence; an abbreviation with a period may end one early. A front-matter field is read by the phrase rules and not by the sentence rule, which is why the envelope is blanked. A phrase of the lists broken across a line break inside a paragraph is not found, since Vale matches within a line. A sentence Vale cannot place — a table cell that ends without a period, a sentence that opens with a code span — is reported at the first line of the block that holds it or follows it, with an empty echo or the block's first words (seen on the kit's own tree: a cell of 159 words in the kit-live proof, and a list item of the module's comparison whose long sentence opened with a command in code font, during the audit). Backstop: the blanking; the echo of the sentence's start in L2, so a reader sees what was counted, and the line of the block above or around it when the echo is empty or the block's first words.
3. **The lists are lists.** A phrase in the forbidden list fires wherever the words stand, in a name, in a quotation in running text, in a sentence about the phrase, inside a hyphenated word such as `self-sufficient`, since a hyphen is a word boundary to the pattern. A Vale comment inside an indented code block, four spaces and no fence, is reported as L6, since the gate masks fences and code spans alone. The plain word of a pair is right for most sentences and wrong for some; two words that only look like a passive — "is red", "is indeed" — are reported by the passive pattern. Backstop: code spans for a phrase mentioned rather than used; `exceptions`; the passive at warning by default.
4. **The hook shows the first findings that fit in 8,000 characters**, the shared cap of limit 14 in [kit-shared-gate-code §4](../../shared/GATE.md#g4), the first always shown; the count line says how many there are; the scan lists them all; a finding renders under the cap when its values are the ones that only point, cut at 80 characters, and a path is bounded by the file system. Not every value is cut: `{plain}` in a fix stands whole, escaped (the error messages above), and the plain word is a dial's text, which nothing here bounds, so a first finding holding a very long one can pass the platform's 10,000 on its own, the break of limit 14 of [kit-shared-gate-code §4](../../shared/GATE.md#g4). Backstop: the count line; the scan; a plain word kept as short as it teaches.
5. **The hook sees a write through the file tools and nothing else.** A shell command, a merge, an editor: the shared limit 1. Backstop: the scan, in CI and before a merge.
6. **Nothing in a document switches a rule off,** and a Vale comment outside a fence or a code span is reported; but a consumer's own `.vale.ini` in the tree, and a `StylesPath` of its own, are never read by this gate, which passes `--config` and `--no-global`, so a consumer running Vale by hand beside this gate sees two configurations. Backstop: the install note says so; `exceptions`, `forbidden` and `simpler` for what the project wants the gate to know.
7. **A document that is not UTF-8** is read with its undecodable bytes replaced, so a count near such a byte may be off by a word. Backstop: the shared limit on encodings; review.
8. **The temporary directory** holds a copy of every covered document for the length of a run, in the system's temporary location. Backstop: removed when the run ends, however it ends.
9. **The envelope ends at the next line that is `---`**, its trailing whitespace ignored, wherever it stands, as the shared envelope reader reads it (shared limit 8), which the gate asks through `envelope_bounds`: when the line meant to close the envelope is no `---` line, for example because a form feed stands before the dashes, the next `---` line further down closes it, even a thematic break, and the document is blanked up to that line, so the prose between is not read. An envelope with no later `---` line at all is not blanked (T7). And after a write, coverage is by pattern alone: a written file the patterns hold is judged though git ignores it, which the scan never lists (shared limit 7). Backstop: the sibling envelope gate, which reads an envelope closed by that later line as invalid when the text up to it is no YAML, and an envelope with no closer as unterminated; the scan's count, which says what it listed.
10. **A departure allows a rule in a document whole**, not on one line, and one by path outlives its document until the scan's note is acted on; the note is not a finding, so a stale entry does not turn the scan red; the note is per entry, so an entry of several patterns with one that matches nothing is not stale. Backstop: the reason names what stands; N3 on every scan; review.
11. **The waits on `vale` are bounded in the hook and in the version probe, and not in the scan's run.** The probe of `vale --version` gets `VERSION_SECONDS`, 5 s, in every mode, and one with no answer is the C12 `no answer in 5 s`. The hook waits `HOOK_SECONDS`, 10 s, for each run of Vale, after a write as the plugin wires it and before one where a consumer wires that, and past it prints the C12 that names the scan; the write goes on. The scan's run has no budget, so a `vale` that hangs there keeps the scan waiting until the CI job's own limit, with no teaching line. Backstop: the C12 lines; fixture T16, which holds both budgets and 5 s left under the hook's timeout; the scan, which waits for vale as long as it takes; the CI job's limit.

**Exit-code contract**: `0` green, or nothing examined (the count line says which); `2` finding — a document is over the ceiling or the limit, holds a phrase of a list at level error, or holds a Vale comment outside a fence or a code span; `1` configuration failure — the checker could not run: the shared failures, this module's C2, C5 and C12. Nothing exits 0 on error.

## 11. Siblings

**Depends on:** [kernel §6](../../kernel/CONVENTIONS.md#k6) — the dials file, where every threshold and level lives, and the territory dialect. Nothing else.

**Kernel alone:** on a bare repository with a `constitution.yaml` that holds no key of this namespace, the hook and the scan cover every Markdown file at the defaults, and the skill carries the six advisory rules; with no `constitution.yaml` at all every run is the shared visible skip naming the file; with no `vale` on PATH every run is the configuration failure naming the install command.

**When module `const-interaction` is installed,** its session-start rule carries the chat half of the language aspect — plain chat language for the same reader — which no hook can measure; this module ships the document half alone. **When module `const-styling` is installed,** its scan holds the twelve markup signatures and this gate holds the prose; a rule about words that the styling guide founds may graduate here ([§12](#t12)). **When module `const-meta-types` is installed,** the envelope this gate blanks is checked there. Each is an optional enhancement; every rule here runs with the kernel alone.
