# MODULE.md — `const-doc-budgets`

*Draft at manifest version `0.0.1`, no open slots. This document is the module's description ([template](../../module-template/MODULE.md)). Every list and table row carries a handle.*

<a id="t1"></a>
## 1. Purpose

A document a project keeps grows with every change that touches it. Nobody measures what that costs the reader, or the model that loads it in every session. The kit's own tree shows it (the research comparison, E2 and E3). The session guide grew from 15,720 to 20,372 characters in one week. The shared code document grew from 24,787 to 42,795 in another. The longest decision record holds 30,126 characters, the longest research comparison 71,590. Each change decides its own length, and no one sees the kind's length move until a reader gives up. This module gives the project a number per group of documents — a ceiling in characters, set from what the group was observed to need. It holds the number in the dials file. It measures every held document against it after each write and in a scan. A ceiling warns while its data are young and blocks only once 30 days of data stand behind it.

<a id="t2"></a>
## 2. Failure class

`self-limiting`: an over-long document is felt by its readers and fixed there; nothing compounds across the repository except a template, whose documents inherit its length. **Entry trigger:** bloat observed, with data. It is a reader or a session saying a document is too long to use. Or it is a document loaded into every session growing past what its readers want. The lengths of its group over time must also be at hand to show it. The kit did not pass it. The module was started ahead of the trigger by the decider's choice, with ceilings set from 15 days of data. That was over the session's objection that no friction signal on document length existed (decision [dec-0052-doc-budgets-module-rulings](../../docs/decisions/dec-0052-doc-budgets-module-rulings.md), section 1).

## 5. Invariant

**No document a ceiling at level error holds is longer, in characters, than that ceiling's `max`. This is so save where an entry of the `departures` dial lifts that ceiling for the document. No document is held by two ceilings, and no ceiling at level error rests on a window shorter than 30 days.** "Holds": among the Markdown files git lists, tracked and untracked, ignored ones excepted, the ones the ceiling's `paths` match. "In characters": as [kernel §7](../../docs/constitution/CONVENTIONS.md#k7) counts them, over the whole file. "Lifts": an entry whose `paths` match the document and whose `allow` names the ceiling; the document is measured and passes. A ceiling at level warning holds its documents to a note, never a finding. The invariant holds after every write of a held document through the file tools and at scan time. Under the shipped wiring no write is refused ([§9](#t9)). After a write, holding is by pattern alone. The hook measures a written file the patterns match whether or not git ignores it. The scan, by contrast, lists only what git does not ignore (shared limit 7).

The advisory rules beside it, each `advisory` in its own text, stated in the skill:

- **B-a.** Set a ceiling from the report, never from a wish. It is the window's longest document plus 10 %, rounded up to a multiple of 1,000. Then no document is over it on the day it is set. *Advisory.*
- **B-b.** A ceiling stays at warning until 30 days of data stand behind it; then it may block. *Advisory; the gate refuses `error` on a shorter window.*
- **B-c.** A document over its ceiling is split or cut, never squeezed: a shorter document that says less clearly is the wrong fix. *Advisory.*
- **B-d.** A ceiling is lowered only from data, in a change of its own with the number and the reason. *Advisory.*
- **B-e.** A document that must stand as written is declared as a departure in the dials file with its reason. Nothing is marked in the document, and no pattern hides it from its ceiling. *Advisory.*

## 7. Dials

| dial | default | read by | meaning |
|---|---|---|---|
| `severity` | `block` | the hook | As every hook gate's ([template §7](../../module-template/MODULE.md#t7)): `block` hands a finding to the model as a block beside the tool result, exit 2, the write already made. `warn` hands it as context, exit 0. The scan ignores it and is red on any finding. It never turns a note into a finding: that is each ceiling's `level`. |
| `log_dir` | absent | all three | As every gate's ([template §7](../../module-template/MODULE.md#t7)). |
| `ceilings` | `[]` | all three | The groups and their numbers: entries `{name, paths, max, level, window: {from, to}}`. `name` is kebab-case and unique, the handle a departure names. An entry's `paths` is gitignore syntax over the Markdown files git lists — a policy's territory by a YAML alias, or patterns of the entry's own. A negated pattern takes files out of this entry alone. An entry's `max` is a whole number of characters, 1 or more. A held document longer than it is B1 at level `error` and N2 at `warning`. An entry's `window` is the first and the last day of the data the number was set from, each written `YYYY-MM-DD`, quoted or not. A ceiling at `level: error` needs `to` 30 days or more after `from`, and a shorter window is a configuration failure. A document two entries hold is a configuration failure. It is one in the hook for the written file, and in the scan for the first in path order. The history report counts such a document under each. Empty or absent: the gate measures nothing, says so at session start, and the scan counts zero. |
| `departures` | `[]` | the hook and the scan | What stands over its ceiling, where, and why: entries `{paths: [<patterns>], allow: [<ceiling names>], reason: <one line>}`. `paths` is gitignore syntax. It takes a pattern for a kind of document, or a number range by a character class such as `docs/records/rec-00[0-3]*.md`. It also takes one file by its path with a leading slash. An entry's `allow` names ceilings that exist. `reason` is required and one line. A line break at either end, which a YAML block scalar gives at its end, is trimmed with the other white space there. A line break inside the reason is refused. A document an entry matches is measured and passes the ceilings it names; the others still apply. An entry that lifts nothing — it matches no document a ceiling it names holds — is N3 on every scan. A malformed entry is a configuration failure naming the entry. So are an unknown field, a name no ceiling carries, an empty or multi-line reason, and a pattern git would misread. The report reads no departure: its data are every document's. |

A consumer's calibration lives in its own dials file, never here; the kit's, as it was set, is dated in [§10](#t10), item L1.

## 8. Boundary examples

Each pair reads *violates / complies*. The gate's own lines are numbers; the boundaries below are the module's judgment lines and the moments where a number is not the answer. Each group stands under the advisory rules of [§5](#t5) it gives pairs to.

**B-a, B-b and B-d — a ceiling, or a target** ([A11.2](../../docs/requirements.md#a11-2), [A11.3](../../docs/requirements.md#a11-3)):

1. A ceiling for records set at 20,000 because records "should be short", with five records already over it. → A target from no data, red on day one / the report's longest record, 30,126, plus 10 %, rounded up: 34,000. A later lowering comes from data, in a change of its own.
2. A ceiling moved to `level: error` on its fifteenth day because a document crossed it. → Refused by the gate, and a block from half the data / left at warning until the window holds 30 days. Meanwhile the excess is cut or split from the note.
3. A median-based ceiling that half the documents of a kind already break. → A percentile, a target for the many / the maximum plus the margin, no document over it when it is set.

**B-c — a cut, or a split** ([A11.2](../../docs/requirements.md#a11-2)):

4. A module document over its ceiling squeezed by dropping its examples and its limits. → Shorter and less true / split along a seam it already has. A long table is moved into a document of its own linked from the first. Or a restated rule is replaced by a link to its home.
5. The session guide over its ceiling, a paragraph moved into a second always-loaded file. → The reader loads it all the same / the paragraph moved into a skill that loads when its activity occurs. The always-loaded text shrinks.
6. A record over its ceiling cut by deleting its options and keeping the ruling. → The reasoning lost / the options kept, a long quotation replaced by a link to its source.

**B-e — a departure, or a hiding place** ([A11.2](../../docs/requirements.md#a11-2)):

7. An accepted record over a ceiling lowered below it, taken out of the ceiling's `paths` by a negated pattern. → Hidden with no reason. Or cut to meet the number by edits its policy does not allow / first the edits its policy allows, where they reach the number. For what they do not reach, a departure over its path, allowing that ceiling, with the reason that accepted records stand as written.
8. Two ceilings over one folder so that a narrower one gives a sub-group more room. → Refused by the gate, since the verdict would hang on the order of the list / the broad entry's patterns narrowed. Or the sub-group is taken out of it by a file pattern. Either way, each group is then under one entry.
9. A departure left in the dials file after its document was deleted. → A reason for nothing, reported on every scan / the entry removed in the change that deleted the document.

## 9. Enforcement honesty

| # | artifact | kind |
|---|---|---|
| E1 | `check-budgets` after a write: B1, N2; this module's dials validated at each read, the C5 texts of [§6](#t6), and `log_dir` by the shared code | `gate`, severity dial `severity`. | E3 | `check-budgets --scan --since <date>`: the history report, not a tree scan | `advisory`: it shapes the reviewer's number (rule B-a), blocks nothing and exits 0 on any data. It judges nothing and says so in its closing line |
| E4 | the hook on `SessionStart` and `session-start.sh`: the line of the always-on content | `advisory`, blocks nothing |
| E5 | the skill `set-ceilings`: B-a to B-e | `advisory` |
| E6 | the effect entry `effect-report.sh`: it informs judgment, gives no finding, never exits 2 and is never red | `advisory` |

Exit codes: `0` green, a report, or nothing examined (the count line says which). `2` is a finding — a held document is over a ceiling at level error. `1` is a configuration failure — the checker could not run: the shared failures, this module's C5 and C12. Nothing exits 0 on error.

**Honest limits:** the limits every gate shares, [kit-shared-gate-code §4](../../shared/GATE.md#g4). This module's own, each with its backstop:

1. **The window is declared, not proven.** The gate checks that `to` is 30 days or more after `from`; it cannot check that the data of those days were read. Nor can it check that the number came from them. Backstop: the report prints the window and the rule of thumb beside the number set; review, at the change that sets it.
2. **A document already over its ceiling is reported after every write to it,** the finding saying the length, not how much this write changed it. Backstop: the first finding says how much to cut; a departure where the document must stand.
3. **The hook sees a write through the file tools and nothing else.** A shell command, a merge, an editor: the shared limit 1. Backstop: the scan, in CI and before a merge.
4. **The report reads the first-parent line of HEAD.** A version that lived only on a merged branch between the line's commits is not in the report's days as it happened. Nor is a commit dated by a clock set wrong. A day is the committer's calendar day. Backstop: the report's lines name the commits and days it read; the branch's own history, reported on the branch.
5. **The report applies today's ceilings to the past.** A path that two of today's ceilings would hold is counted under each in the report, since the report judges nothing. The gate refuses the overlap in today's tree. Backstop: the scan.
6. **A count is of the whole file.** Link targets, the envelope and code count as text does, since the reader loads them. A group heavy in tables or links gets a higher number from its own data. Backstop: the ceiling is set per group from that group's lengths.
7. **A departure lifts a ceiling for a document whole,** with no number of its own. One by path outlives its document until the scan's note is acted on, and the note is not a finding. Backstop: the reason names what stands; N3 on every scan; review.
8. **A configuration failure stops the whole gate.** A malformed entry — a ceiling at error on a short window, a departure naming no ceiling — fails every read. While it stands no document is measured, in the hook or the scan. Two ceilings over one document fail every scan but the history report, and in the hook a write of that document alone. Backstop: the failure is exit 1 with its line, which a hook shows the user and CI turns red; the scan in CI.
9. **The report follows a symbolic link only within the commit's tree.** A link whose target is an absolute path, or leaves the tree by `..`, is left out of the report. The scan, by contrast, measures it when the file it leads to exists on the disk, even back inside the repository. Backstop: a ceiling set from the report is checked by the scan, which reports a document over it.

## 11. Siblings

**Depends on:** [kernel §6](../../docs/constitution/CONVENTIONS.md#k6) — the dials file, where every ceiling lives, and the territory dialect — and [kernel §7](../../docs/constitution/CONVENTIONS.md#k7), the definition of a character. Beside the kernel it needs the Python package `constitution-layer-kit`, which pip installs, as it needs Python and PyYAML. That package is the kit's shared gate code and no sibling ([law 3 of CLAUDE.md](../../CLAUDE.md#law-3)). The external tool its gates preflight is git, with Python 3.12 and PyYAML. Without git no run of the module examines anything. Without git, the hook, the scan, the report and the session-start printer each end in the shared configuration failure `C3` and never in a green. Nothing else.

**Kernel alone, with that package installed:** take a bare repository with a `constitution.yaml` that holds `module_prefix` and no key of this namespace. There the gate measures nothing, the session start says so in one line, and the scan counts zero. The report there, run by hand over the repository's history with a ceiling written at warning, gives the data a first ceiling is set from. With no `constitution.yaml` at all every run is the shared visible skip naming the file.

**When the project's policies declare territories in the dials file,** a ceiling points at one by a YAML alias and holds exactly that kind. The module still reads only its own namespace. **When module `const-meta-types` is installed,** the envelope this gate counts as text is checked there. **When module `const-language` is installed,** it holds how the prose reads and this gate how long the document is. When it is installed, a document cut to meet a ceiling is read there again. Each is an optional enhancement; every rule here runs with the kernel alone.

## 12. Deferred

The deferrals every gate shares stand in [kit-shared-gate-code §1](../../shared/GATE.md#g1), and this module's own follow, each with its signal.

1. **A ceiling by meta-type** — an entry filtered by the envelope's `type` beside its paths. Signal: a consumer whose documents of one meta-type are scattered across folders no pattern names.
2. **The change a write made, in the finding** — the difference an `Edit` made, from its `old_string` and `new_string`. With it, a finding on an already long document says whether this write made it longer. Signal: a consumer finding the repeated finding of limit 2 of [§9](#t9) noise.
3. **A `PreToolUse` mode that refuses only a write making a document over its ceiling longer.** The shipped hook judges after the write. Wired before it, the gate refuses every write that leaves a document over its ceiling, a partial cut included. Signal: a consumer asking to be stopped before the write, at the price of the reconstruction of an `Edit`.
4. **A number derived by the gate** — the ceiling computed from the history at each run instead of declared. Signal: a consumer whose declared numbers drift from the report for want of anyone to set them.
5. **The effect report's other ways.** It has no B3 rule: the hook runs after the write, so the document already stands. The fix the red teaches may be an act on another file (a departure in the dials file), which B3 would count as a workaround. And a ceiling at warning gives only a note, which is no red to walk around. It has no B5 rule after a red, and no B6 rule, since the gate has no output shape to hold. Its W4 sees an edit of the dials file only through the call's own text. So a line that names none of the ceilings' words is not a moment, and a change made through the shell is not seen. Signal: a ceiling raised or a document left over its ceiling found, by review, with the report counting it applied, twice.
